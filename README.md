# Professor Review Rating Prediction

A machine learning project that predicts professor ratings from student reviews using natural language processing (NLP).

## Technologies
Python, PyTorch, Hugging Face, Pandas, GPT-2

## Project Overview
- Collected and processed 690 professor reviews using the PlanetTerp API.
- Fine-tuned a pretrained GPT-2 transformer to predict ratings from 1 to 5 stars.
- Achieved 65.2% test accuracy.

## Files
- `CMSC320_HW4.ipynb` — Python notebook containing the model implementation and evaluation.
- PowerPoint presentation — Project overview, methodology, and results.
